## 🛠️ What I Worked On

Across these projects, my responsibilities included:
- Translating client briefs into complete, working websites — from layout and design to functionality
- Building both frontend-only static sites and full-stack applications with backend APIs
- Implementing authentication (JWT), admin panels, and CRUD operations
- Integrating third-party services (Razorpay payments)
- Ensuring full responsiveness across desktop, tablet, and mobile devices
- Submitting daily progress reports and iterating based on faculty/mentor feedback
